# BR-01 design notes — land units in the Línea system

Brief: Brazilian land owners, heirs reading an old escritura, buyers and corretores comparing
listings, agronomy students — mostly on phones, often outside big cities. They type "alqueire em
hectare" and get four different answers from the first four results. The page has one job: give
the value **for their state**, show where it comes from, and say so when sources disagree.

## What carries over from Línea (unchanged)

Archivo (expanded display, tabular figures), black/white/warm grey, one line color per tool, the
station pictogram, the answer-first hero, the result panel with the spring number roll, the sticky
result bar on phones, FAQ, sources, disclaimer, review badge. No new font, no new component kit.

## What is new, and why

| Element | Decision | Why it is specific to this brief |
|---|---|---|
| Line color **terra roxa** `#8c2f1c` (dark `#f2876b`) | One line for all land tools | The red soil of the alqueire-paulista country. 8.3:1 on white, 7.3:1 on the dark background. Deliberately darker and redder than the clay/terracotta "AI accent". |
| **State first** | "Estado do imóvel" is the first field | The answer depends on the state; asking first is the honest UX. |
| **Value used + source card** | Under the result: area, braças, where it is used, the source with its kind (órgão oficial, tabela oficial histórica, pesquisa acadêmica, imprensa, site comercial) and the verification state | Competitors print a number with no source; trust is the product. |
| **Divergence notice** | Warning tone, one-tap chips for each value (aria-pressed) | "Never pick silently": BA, MT, MA, PI, AL, SE show both values. MT/MA/PI have no default at all. |
| **The plot drawn to scale** (the memorable element) | The unit as a rectangle in braças next to a dashed 1 ha square; on static pages, small multiples on a surveyor's grid every 50 braças | Shapes explain "paulista is half a mineiro" instantly. Emphasis form (one hue + neutral reference); all values written as text beside it, so nothing depends on reading the drawing. |
| Pictograms | Alqueire = plot in four quartas; hectare = measured square; tarefa = furrows; litro = seed measure | Same 24 px stroke grammar as the MX set. |

Motion (all ≤ 250 ms, ease-out, off under `prefers-reduced-motion`): the headline rolls to its new
value (shared `AnimatedNumber`, rounding per unit instead of per cent); the source card fades up
4 px when the unit or state changes; the scale plan grows from 97 % when the unit changes; the swap
icon turns 180°. Nothing moves on its own.

## Self-critique and next passes

- The headline uses a short unit ("20,6612 alq.") because the full "alq. paulista" wrapped on
  desktop; the label above and the sentence below name the variant.
- On 390 px the unit select truncates long names ("Tarefa alagoana e sergipana (3.0…"); the
  native picker shows them in full. A custom listbox would cost JS for little gain.
- The state table becomes one block per state on phones (ARIA roles keep table semantics).
- Archivo has no `≈` glyph; the sign renders in the fallback face (see LAUNCH_CHECKLIST §7.3).
